# GOAT Cam 1.0.0 — Release

Primeira release comercial do aplicativo Android GOAT Cam.

## Identidade
- Nome: GOAT Cam
- Package ID: `com.goatpro.ip`
- Version name: `1.0.0`
- Version code: `100`
- Android target/compile SDK: 36

## Arquivos oficiais
- `GOAT-Cam-1.0.0-Release.apk`: instalação/teste direto em Android.
- `GOAT-Cam-1.0.0-Play.aab`: arquivo destinado ao Google Play Console.

## Assinatura
O APK foi validado com APK Signature Scheme v2 e v3.
O AAB foi validado com a assinatura da chave de upload.

Certificado SHA-256:
`F4:14:95:E0:CC:F3:55:A9:8C:DF:8D:28:B3:3A:81:1A:1F:EA:B4:12:EB:D2:F9:7F:66:50:92:69:97:FF:A5:0C`

A chave privada e a senha não ficam no GitHub. O backup privado deve ser guardado fora do repositório.

## Compatibilidade
O protocolo interno `GOAT_PRO_IP_V1` foi mantido para preservar a integração já existente com o GOAT PRO Studio.

## Observação de instalação
As builds de teste anteriores foram assinadas como debug. A Release 1.0 usa uma assinatura própria, portanto pode ser necessário desinstalar a build de teste antes de instalar o APK release.
