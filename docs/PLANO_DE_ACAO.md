# GOAT PRO IP — Plano de ação

## Objetivo
Transformar o smartphone em uma câmera IP simples, gratuita e integrada ao GOAT PRO Studio, mantendo o usuário dentro do ecossistema GOAT PRO e evitando dependência de aplicativos de terceiros.

## Build 1 — Base funcional
- Android como primeira plataforma.
- Câmera traseira e frontal.
- Resoluções 720p e 1080p.
- Alvo de 30 FPS.
- Iniciar e parar transmissão.
- Exibição do IP e da porta.
- Interface GOAT PRO IP em dourado/preto.
- Transmissão local via Wi-Fi.
- Integração inicial com o GOAT PRO Studio por IP manual.

## Build 2 — Refinamento
- Áudio opcional.
- Lanterna.
- Copiar IP com um toque.
- Status de conexão.
- Tela “Conectado ao GOAT PRO Studio”.
- Ajustes de estabilidade e experiência de uso.

## Build 3 — Integração automática
- GOAT PRO Studio localizar o celular automaticamente na mesma rede.
- Conexão simplificada.
- Reduzir ou eliminar a necessidade de digitar IP manualmente.

## Diretriz técnica
Primeiro provar que a base funciona com estabilidade. Depois ampliar recursos e integração.

## Ordem de validação
1. Fazer o aplicativo transmitir vídeo corretamente.
2. Mostrar IP e porta corretamente no celular.
3. Abrir a transmissão dentro do GOAT PRO Studio.
4. Depois melhorar automação, estabilidade, áudio e recursos extras.

## Fluxo de testes
- Desenvolvimento em etapas pequenas e testáveis.
- Funcionamento real antes de adicionar novos recursos.
- Versões de teste para instalação em Android.
- Os resultados dos testes orientam a build seguinte.

## Definições fechadas
- Nome: GOAT PRO IP.
- Função: usar o smartphone como câmera IP do GOAT PRO Studio.
- Plataforma inicial: Android.
- Identidade: cores invertidas da marca GOAT PRO — fundo dourado e elementos pretos.
- Estratégia comercial: aplicativo gratuito como extensão do GOAT PRO Studio.
- Prioridade: MVP funcional, simples e estável antes de ampliar recursos.

## Princípio do projeto
O GOAT PRO IP não deve virar outro projeto gigante no primeiro momento. A função principal é abrir a câmera do celular, transmitir pela rede local com boa estabilidade e permitir que o GOAT PRO Studio use essa imagem como fonte de vídeo.
